Which native tokens do I need for network fees?

Learn why each blockchain network requires its own native fee token.

Updated 4 months ago by Jake Urban

There is no single token or minimum balance required across every network supported by Wavel. Each network defines its own fee model and uses a native token to pay for transactions.

Before making a transaction

  • Check which network the asset is on.
  • Keep a small balance of that network's native fee token.
  • Review the fee estimate shown by Wavel.
  • Do not send your entire native-token balance if you still need to transact on that network.

Fees change with network demand and transaction complexity. Some networks may also require account creation, token-account, storage, or rent costs. Wavel displays applicable estimates during review; the network, not Wavel, charges these fees.
