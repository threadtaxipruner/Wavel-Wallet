Keep up with the latest Wavel updates for Windows and macOS.

v2.8.0 Windows macOS August 14, 2026

Wavel 2.8.0

What's new

•Faster startup and more reliable session restore.
•Unified balances and activity across supported networks.
•Clearer asset, network, recipient, and fee details before approval.
•Native desktop notifications for transaction status updates.
v2.7.2 Windows July 30, 2026

Windows reliability update

Fixes and improvements

•Improved update handling and reduced interruptions during upgrades.
•Sharper rendering on high-resolution and mixed-DPI displays.
•More reliable address and transaction ID clipboard actions.
•Fixed a lock-screen delay after waking the computer.
v2.7.1 macOS July 18, 2026

Refined for macOS

Fixes and improvements

•Lower resource use and better Apple silicon performance.
•Wavel now remembers window size and position between sessions.
•Refined keyboard shortcuts and focus states.
•Resolved a visual flicker when returning from the menu bar.
v2.7.0 Windows macOS June 26, 2026

Portfolio and activity refresh

What's changed

•Daily and monthly portfolio changes are easier to review.
•Search transfers and swaps by asset, address, or network.
•Improved loading feedback and error messages throughout Wavel.
v2.6.0 Windows macOS May 29, 2026

Security improvements

Security

•Suspicious addresses and transaction requests are flagged before approval.
•Added configurable auto-lock after computer inactivity.
•Sensitive wallet data remains encrypted on your computer.
