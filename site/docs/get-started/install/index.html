Wavel for Windows and macOS

Install Wavel

Download the official desktop app and verify that your computer meets the supported operating-system requirements.

System requirements

PlatformRequirementPackage
WindowsWindows 10 or later64-bit installer
macOSmacOS 12 Monterey or laterUniversal binary
!
Use the official download

Download Wavel only from wavel.app. Avoid installers sent through messages, ads, unofficial mirrors, or unverified repositories.

Download

  1. 1
    Open wavel.app/#download.
  2. 2
    Choose the installer for Windows or macOS.
  3. 3
    Open the downloaded package and follow the operating-system prompts.
  4. 4
    Launch Wavel and choose whether to create a new wallet or import an existing one.

After installation

Choose Create a new wallet if you are starting fresh. Choose I already have a wallet only when restoring a recovery phrase you control.
