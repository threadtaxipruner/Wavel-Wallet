# Contributing

Thank you for helping improve Wavel.

1. Fork the repository and create a focused branch.
2. Keep changes small and avoid adding generated files or external trackers.
3. Test the site on desktop and mobile viewports.
4. Verify that links and static assets load locally.
5. Open a pull request describing the behavior and your verification steps.

Do not commit credentials, private keys, recovery phrases, production data,
analytics identifiers, or proprietary third-party assets.
